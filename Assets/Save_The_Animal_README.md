# Save The Animal

> Unity 기반 2D 매치3 퍼즐 게임\
> 개발 상태: In Progress

## 프로젝트 소개

`Save The Animal`은 같은 종류의 타일을 매칭해 동물을 구조하고,
구조한 동물을 컬렉션으로 모으는 매치3 퍼즐 게임입니다.
Unity와 C#을 사용해 게임의 핵심 플레이 시스템을 직접 설계하고 구현하고 있습니다.

-   **장르:** 매치3 퍼즐 / 수집형
-   **엔진 및 언어:** Unity / C#
-   **개발 형태:** 개인 프로젝트
-   **개발 상태:** 개발 진행 중

## 기획 의도

매치3 퍼즐의 직관적인 조작과 동물 구조·수집의 보상 구조를 결합했습니다.
스테이지를 클리어할 때마다 동물을 구출하고,
구출한 동물을 보호소 컬렉션에 기록하는 것을 주요 목표로 합니다.

## 주요 구현 내용

현재까지 진행한 핵심 시스템은 다음과 같습니다.

-   **게임 보드:** 7×7 타일 보드 구성
-   **타일 조작:** 타일 클릭 및 인접 타일 스왑
-   **매치 판정:** 동일한 타일의 연결 상태 탐지
-   **타일 제거 및 낙하:** 매치된 타일 제거 후 빈 공간을 채우는 처리
-   **연쇄 매치:** 타일 낙하 이후 새롭게 발생하는 매치 처리
-   **스테이지 연동:** 구조 목표 수량과 진행 상황 관리
-   **실패 처리:** 유효하지 않은 스왑의 원위치 복귀 모션
-   **UI:** TextMeshPro 기반 게임 진행 정보 표시

## AI 활용 및 개발 방식

이 프로젝트는 처음으로 Unity 게임 개발을 진행한 개인 프로젝트입니다.
개발 초기에는 게임의 핵심 동작과 코드 구조를 직접 이해하고 구현하는 데 집중했습니다.

1.  필요한 게임 시스템을 작은 기능 단위로 나눴습니다.
2.  핵심 로직은 직접 코드를 작성하며 구현했습니다.
3.  구현 과정에서 발생한 오류와 예상과 다른 동작을 AI와 함께
    분석했습니다.
4.  AI가 제안한 수정 방향을 검토하고 Unity에서 직접 실행해 결과를
    확인했습니다.
5.  실제 동작을 기준으로 코드를 수정하고 다시 테스트했습니다.

**AI의 역할:** 오류 원인 분석, 디버깅 방향 제안, 코드 오류 수정 및 개선
**본인의 역할:** 시스템 설계, 핵심 코드 작성, AI 제안 검토, Unity 적용, 실행 및 동작 검증

AI가 제시한 답을 그대로 적용하기보다 게임에서 기대하는 동작과 실제 실행 결과를 비교하면서 문제를 해결하는 방식으로 개발했습니다.

## 개발 과정에서 다룬 문제

-   매치가 정상적으로 감지되지 않는 문제를 확인하고 판정 로직을
    수정했습니다.
-   유효하지 않은 타일 스왑이 원위치로 돌아오지 않는 문제를 확인하고
    복귀 동작을 추가했습니다.
-   타일 제거·낙하·연쇄 처리 과정에서 발생하는 동작 순서를 점검했습니다.
-   자동 연쇄 제거로 스테이지 목표가 예상보다 빠르게 달성되는 상황을
    확인하고 목표 수량을 조정했습니다.
-   UI 배치와 Canvas 스케일 문제를 점검하며 화면 구성을 조정했습니다.
